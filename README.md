## 📖 Sobre o projeto

O **Mente Serena** é um projeto acadêmico desenvolvido durante a disciplina de **Desenvolvimento de Aplicações Web**.

O projeto surgiu com a proposta de desenvolver uma plataforma relacionada à **saúde mental**, simulando um ambiente capaz de conectar pessoas que buscam acolhimento a profissionais voluntários.

Além de trabalhar a temática de saúde mental, o desenvolvimento teve como objetivo colocar em prática conceitos de desenvolvimento web, responsividade, organização de interfaces e interação com o usuário.

A versão atual funciona como uma aplicação **Front-end**, desenvolvida utilizando HTML, CSS, Bootstrap e JavaScript.

---

## 🎯 Objetivo

O objetivo do projeto é representar uma plataforma de apoio psicológico que permita ao usuário navegar por diferentes recursos relacionados à saúde mental.

Entre as funcionalidades e páginas desenvolvidas estão:

- 👨‍⚕️ Busca e visualização de profissionais voluntários;
- 📅 Fluxo de agendamento de atendimentos;
- 📰 Área de conteúdos e artigos sobre saúde mental;
- ❓ Página de perguntas frequentes;
- 📞 Área de contato;
- 👤 Cadastro e acesso de usuários;
- 📱 Interface responsiva para diferentes tamanhos de tela;
- 🎨 Interface voltada para uma experiência simples e acolhedora.

> A versão atual possui foco principalmente na interface e experiência do usuário. Algumas funcionalidades representam fluxos que serão integrados a um Back-end futuramente.

## 💻 Como executar o projeto

Como a versão atual utiliza apenas tecnologias Front-end, não é necessário instalar dependências.

### 1. Clone o repositório

```bash
git clone https://github.com/CaioDev05/SaudeMentalTrabalho.git
```

### 2. Entre na pasta

```bash
cd SaudeMentalTrabalho
```

### 3. Execute o projeto

Abra o arquivo:

```text
index.html
```

diretamente no navegador.

Para uma melhor experiência durante o desenvolvimento, também é possível utilizar uma extensão como **Live Server** no Visual Studio Code.

## 🔄 Próximas etapas

O projeto continuará sendo desenvolvido além da versão apresentada na disciplina.

A intenção é transformar o Mente Serena em uma aplicação **Full Stack**, permitindo uma interação mais completa entre usuários, profissionais e a plataforma.

### Front-end

- [ ] Migrar a aplicação para **React**;
- [ ] Componentizar elementos reutilizáveis;
- [ ] Implementar gerenciamento de estado;
- [ ] Integrar o Front-end com a API;
- [ ] Melhorar validações e feedbacks ao usuário.

### Back-end

- [ ] Desenvolver uma **API REST utilizando .NET**;
- [ ] Utilizar **Entity Framework Core** para acesso e persistência dos dados;
- [ ] Integrar a aplicação a um banco de dados;
- [ ] Implementar cadastro e autenticação de usuários;
- [ ] Implementar cadastro de profissionais;
- [ ] Criar gerenciamento de disponibilidade;
- [ ] Persistir e gerenciar agendamentos;
- [ ] Criar regras de negócio e validações no servidor.

### Evolução esperada

```text
React
   │
   │ HTTP / JSON
   ▼
.NET Web API
   │
   ▼
Entity Framework Core
   │
   ▼
Banco de Dados
```

Com essa evolução, o projeto deixará de representar apenas os fluxos através da interface e passará a possuir dados e operações reais sendo processados pelo Back-end.
